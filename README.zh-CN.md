# 万象宝典 · wxq-codex

[English](README.md)

王者万象棋的边打边查页面:上面是升级费用计算器,下面是卡牌图鉴和棋手图鉴,一页放下,iPad 上开着就能用。

线上地址:https://yuuteng.github.io/wxq-codex/

![计算器](docs/screenshot.jpg)

## 计算器

点三排按钮:有没有弈星(无 / 有 / 觉醒)、当前等级、游戏里升级按钮上显示的能量数。页面据此算出连升到每个更高等级要掏的总能量,弈星省下的部分在括号里标出。经验模型来自我自己的笔记,规则和推导出的费用表印在页面底部。

## 卡牌图鉴

![图鉴](docs/gallery.jpg)

- 英雄、天赋、装备、效果四个 tab,筛选和官网一致:英雄按阵营、关键词、品阶;天赋和效果按解锁分组;装备按相关和类型。
- 右栏显示卡面、说明、关键词解释、技能、属性和觉醒形态。相关卡点开放大。
- 卡牌数据在打开页面时从官网读取,版本更新数值不会滞后。`data/` 里的快照只在读取失败时兜底。
- 每个 tab 的列表只建一次,之后切筛选只做显示隐藏,图片不重刷。首屏出来后后台预取其它 tab。

## 棋手

![棋手](docs/roles.jpg)

19 位棋手:立绘、台词、技能 / 秘技 / 专属三项能力,以及关联卡牌列表。

## 离线与缓存

Service Worker 对图片和字体见一次就缓存,页面文件和数据每次向服务器校验。列表头像、英雄图标和棋手立绘镜像在 `img/cdn/`,首屏不依赖慢的图片源;没有镜像的自动回退到原链接。

## 目录

| 路径 | 作用 |
|------|------|
| `index.html` | 计算器、页面骨架、规则和费用表 |
| `cards.js`、`cards.css` | 卡牌图鉴 |
| `roles.js`、`roles.css` | 棋手图鉴 |
| `sw.js` | Service Worker |
| `data/cards-snapshot.json` | 兜底数据快照 |
| `data/mirror.json`、`img/cdn/` | 镜像的列表图片和地址映射 |
| `img/card/`、`img/role/` | 切图和背景 |
| `fonts/` | 汉仪旗黑 60S 和 75W |
| `scripts/sync.sh` | 游戏更新后刷新快照和镜像 |

## 版本更新后

```sh
scripts/sync.sh
git commit -am "sync" && git push
```

## 本地运行

```sh
python3 -m http.server 8000
```
